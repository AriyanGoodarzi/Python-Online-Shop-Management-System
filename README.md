# Python Online Shop Management System

A console-based online shop management system developed using **Python** and **Object-Oriented Programming (OOP)**.

This project simulates the basic operations of an online store, allowing users to register, log in, browse products, manage shopping carts, complete orders, generate invoices, and select shipping methods.

## Features

### 1. Product Management
- Display available products.
- View detailed product information.
- Manage product prices and stock quantities.
- Save and load product information using CSV files.
- Track product availability.

### 2. User Management
- User registration.
- User login and logout.
- User profile management.
- Track customer purchases.

### 3. Shopping Cart
- Add products to the shopping cart.
- Remove products from the cart.
- Select product quantities.
- Check product availability.
- Calculate the total price.

### 4. Checkout and Invoice Management
- Process customer orders.
- Automatically update product stock.
- Generate invoices.
- Display invoice details.
- Save invoices as TXT files.
- Simulate invoice payment.

### 5. Shipping Management
- Standard delivery.
- Express delivery.
- Store pickup.
- Calculate shipping costs.
- Display estimated delivery times.

### 6. Additional Features
- Interactive console menu.
- Input validation.
- Basic exception handling.
- Help and information section.
